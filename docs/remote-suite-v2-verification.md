## 可用功能

Windows 连接电台后，手机通过浏览器查看状态、收听、申请操作权、换信道/扫描/调音量，并在主机分别授权后使用语音、APRS 消息和位置发送。套件还包括 APRS 会话/ACK/有限重试、地图换源/轨迹/聚合、接收音频频谱/瀑布、低带宽模式、网关小时统计、主机信标任务、客户端角色与撤销、地址二维码/连接诊断、配置迁移、脱敏日志/审计、离线演练和 PWA。

上网域名、后端端口、密码、地图源与网关均由使用者配置；程序没有内置使用者的私人域名、密码或证书。按照包内 [简单配置方法](../简单配置方法.md) 配置，建议先只接收。

## Windows 卡死与现场验证

已限制原生接收/TNC/地图/日志积压，将蓝牙 socket 关闭移出主线程，并修复连接与引擎生命周期风险；具体复现和压力测试见 [Windows 卡顿检查](windows-hang-audit.md) 及 [原生接收说明](windows-native-receive-hardening.md)。没有取得用户实际“未响应”时的线程堆栈，不能认定故障根因或保证所有卡死已消除。

软件验收均使用隔离回环服务、模拟电台和合成媒体/定位；未连接真实 N7500，未进行真实 RF、PTT 或信标发射。以下需实际设备现场确认：

- N7500 在不同蓝牙环境下长时间接收、系统休眠/恢复和断开；复测先依次加入网关、地图、一个手机收听，记录出问题时的时间/CPU/内存/挂起堆栈。
- 实际手机的 HTTPS 登录、麦克风音质、GPS 精度、主屏幕安装/启动和后台限制。窗口测试覆盖 Chromium 软件路径，不能替代所有 Android/iOS 浏览器兼容性。
- 极慢网络和磁盘的长期表现；当前队列保护范围见对应文档，接收字节/提交计数不表示无线丢包率或射频交付。

频谱是接收音频频谱；位置/消息确认和审计 accepted 表示软件接受请求。远控、PTT 和信标任务仍需各自授权，重连不恢复旧发射或补发旧任务。以上现场边界随测试包一起提供。
