# Windows 离线语音合成模型

HTCommander 除 Windows 系统声音外，还可使用两个可选的离线中英文合成模型。模型文件较大，需要自行下载，安装完成后合成在电脑本地进行。

1. 在软件的“设置 → 通信 → 语音合成”中点击“打开模型目录”。
2. 下载需要的模型，并使用支持 `.tar.bz2` 的解压软件完整解压。把解压得到的模型文件夹放进刚打开的目录。
3. 返回设置页点击“刷新声音”，在声音列表中选择模型和音色，再点击试听。

可选模型：

- [Kokoro 1.1 中英文模型](https://k2-fsa.github.io/sherpa/onnx/tts/all/Chinese-English/kokoro-multi-lang-v1_1.html)：103 个音色，包括中文男声、女声和英文声音。解压后文件夹名应为 `kokoro-multi-lang-v1_1`，其中直接包含 `model.onnx`、`voices.bin`、`tokens.txt`、词典和 `espeak-ng-data`。
- [MeloTTS 中英文模型](https://k2-fsa.github.io/sherpa/onnx/tts/pretrained_models/vits.html#vits-melo-tts-zh-en-chinese-english-1-speaker)：一个中英文音色。解压后文件夹名应为 `vits-melo-tts-zh_en`，其中直接包含 `model.onnx`、`tokens.txt`、`lexicon.txt`、`date.fst` 和 `number.fst`。英文词语受模型词典限制。

避免把文件夹套成两层，例如模型目录内应直接存在 `kokoro-multi-lang-v1_1/model.onnx`。模型来源及许可请查看下载页面与模型包中的 LICENSE 文件。

语速滑块适用于离线模型；音调滑块对这两个模型无效。首次合成需要加载模型，速度取决于电脑性能。试听只在电脑扬声器播放；射频发送仍使用软件原有的发射控制。

Windows 的“朗读音量”同时作用于本机试听和电台朗读，默认 1.5 倍，1 倍为原始电平；过高的峰值会平滑限制。可以先试听，再逐步调高，注意避免声音失真。
