# 远程运行仪表盘

登录手机远程页面后，顶部的“运行仪表盘”自动显示电台、网关、APRS 投递及近期操作摘要，无需申请操作权。

- 电台连接、上次报告的接收/发射/扫描状态与 0–15 信号等级。该等级不是校准的 dBm。
- 上次收到电台状态报告的 UTC 时间与经过秒数。网页刷新时间不会冒充电台报告时间；服务启动后只有缓存数据时，报告时间显示未知。断开连接会清除时间记录。
- 上次报告的信道及接收频率；没有报告信道时显示配置的 A 信道，并明确标注来源。扫描时优先使用实际报告的信道。
- APRS-IS 启用、连接/已验证/只读状态与最近 24 个 UTC 小时的 RF/IS 接收、上行、下行请求、丢弃及故障计数。
- 最近最多 100 条内存投递记录的等待 ACK、确认、拒收、超时及取消数量。
- 当前远程 WebSocket 连接数。同一浏览器登录可以产生多条连接，数量不等于独立用户数。
- 最近五条操作的 UTC 时间、客户端编号、固定动作与固定结果。摘要不含密码、地址、消息正文、位置或音频。

数据尚未提供时显示“未知”。电台状态不连续上报，经过秒数变大本身不证明断线。网关小时统计仅本次运行保留；软件请求接受、队列提交及计数均不证明实际射频发送或交付。

## 验证（2026-10-03）

- `remote_dashboard_test.dart`：实际报告信道优先、配置来源、无电台未知值、未来时间拒绝、小时去重/边界/非法计数/溢出、脱敏与拷贝隔离。
- `control_lease_test.dart`：生产 WebServerHandler + 真实回环 HTTP 登录/WebSocket 验证状态报告的时间记录、连接数和断开/重连后的未知时间。
- `aprsis_manager_test.dart`：模拟网络验证网关连接、登录验证与禁用后的状态可查询，避免仅瞬时通知而无法进入仪表盘快照。
- `remote_mobile_page_test.cjs`：运行实际页面脚本，验证正常/断开/未知显示、频道文本插入及活动字段脱敏。
- 全量 500 项 Flutter 测试通过；静态分析无问题；手机脚本通过。
- 实际浏览器通过模拟主机 HTTP 登录，检查 390px 视口下仪表盘、实际报告信道、小时汇总、连接计数、操作权活动、断开与未知值。页面内容宽度与滚动宽度一致，无横向溢出；控制台无脚本错误。

开发验证只使用回环服务及模拟 broker 数据，没有连接 N7500，没有执行实际 RF/PTT/信标发射。Windows 测试包验证状态以对应 GitHub Actions 和发布核验记录为准。
