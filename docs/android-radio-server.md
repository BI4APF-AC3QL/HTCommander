# Android 电台连接与远控服务器

HTCommander Android 版可直接通过系统蓝牙配对连接支持的电台，也能把同一部手机作为远控主机：应用连接电台后，可在“设置 → 服务端 → 手机远程操控设置”启用网页服务。其他设备在同一 Wi-Fi 内打开页面显示的 Android 本机地址并登录，即可使用已有手机远控页面。

Android 的“设置 → 许可证 → 位置”可点“使用本机 GPS 定位”获取一次当前坐标，允许系统定位权限后会保存为手动位置，供电台位置、APRS-IS 范围筛选和卫星跟踪共用。它不会后台持续跟踪；移动后需要重新获取，或改用电台 GPS。保存坐标不会单独触发发送；如电台已配置自动信标，请按现有信标设置确认何时会通过射频发送位置。

## 首次连接电台

1. 在 Android 系统蓝牙设置中与电台完成配对。
2. 打开 HTCommander，授予蓝牙“附近设备”权限。
3. 进入电台连接页面，选择已配对的电台并连接。只有应用内显示已连接并取得电台状态后，才表示控制链路建立。
4. Android 版支持系统蓝牙连接和应用现有电台控制、APRS、地图、卫星、音频及日志页面。AGWPE 是可在 Android 上运行的 TCP 网络服务；USB/串口电台连接和串口 GPS 则仍依赖桌面平台接口，不能由 Android RFCOMM 蓝牙替代。

## 开启 Android 远控服务器

1. 进入“设置 → 服务端 → 手机远程操控设置”。
2. 开启“允许局域网 / VPN 远程访问”，设置至少 12 位密码。
3. 端口可保留 8080；再开启“启用网页服务”并保存。
4. 手机显示的本机 IP 与端口就是同一 Wi-Fi 下的访问地址，例如 `http://192.168.1.24:8080/`。从另一台手机或电脑浏览器打开，输入访问密码。
5. Android 会显示常驻通知并保持服务进程运行。停止时回到相同设置关闭网页服务。此模式需要 Android 保持网络可用，并会增加一些耗电。

局域网 HTTP 可用于登录、收听及控制，但 Android 浏览器会限制非安全页面的麦克风和定位等能力。如需在外网使用，建议接入 VPN 或将 Android 端口经 HTTPS 反向代理发布；不要直接把无 TLS 的 8080 暴露到公网。手机浏览器的麦克风和定位功能需要可信 HTTPS 页面。卫星下行跟踪可由 Android 本机使用观测位置；网页远控的数据范围仍取决于本机与浏览器权限。

## 平台边界

Android 端复用桌面相同的 Flutter 电台协议、APRS 处理、地图、频谱、卫星计算、Winlink 和远程权限逻辑，并支持本机接收语音循环录音。Android 录音片段可从音频设置逐条导出。Android 设置的“服务”选项卡还可启用 AGWPE TCP 服务器与 Home Assistant MQTT 桥接；启用任一项时，系统会显示常驻通知并保持网络服务运行。串口 GPS、USB/串口电台适配、桌面软件更新和串口网关仍依赖桌面平台接口，不属于 Android 端能力。

连接电台、网页服务、AGWPE、Home Assistant MQTT 或本机循环录音运行时，Android 显示常驻通知并持有部分唤醒锁；断开全部电台并关闭其他正在使用的功能后会释放。清除应用最近任务不会主动停止已开启的服务；系统强制停止应用、厂商省电策略、Wi-Fi 休眠和后台限制仍可能中断服务，需在目标手机实测。AGWPE 仅应在可信局域网/VPN中开放；它面向兼容客户端的 TCP 接口不提供远程登录密码保护。
