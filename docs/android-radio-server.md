# Android 电台连接与远控服务器

HTCommander Android 版可直接通过系统蓝牙配对连接支持的电台，也能把同一部手机作为远控主机：应用连接电台后，可在“设置 → 服务端 → 手机远程操控设置”启用网页服务。其他设备在同一 Wi-Fi 内打开页面显示的 Android 本机地址并登录，即可使用已有手机远控页面。

Android 的“设置 → 许可证 → 位置”可点“使用本机 GPS 定位”获取一次当前坐标，也可开启“持续使用手机 GPS 定位”。持续定位会更新同一手动位置源，供电台位置、APRS-IS 范围筛选和卫星跟踪共用；启用后会显示 Android 常驻服务通知，并在应用切到后台时继续运行，增加耗电。关闭后保留最后一次坐标。开启持续定位前需授予定位权限；如电台已配置自动信标且允许发送，位置更新可能改变信标内容。

## 首次连接电台

1. 在 Android 系统蓝牙设置中与电台完成配对。
2. 打开 HTCommander，授予蓝牙“附近设备”权限。
3. 进入电台连接页面，选择已配对的电台并连接。只有应用内显示已连接并取得电台状态后，才表示控制链路建立。
4. Android 版支持系统蓝牙连接和应用现有电台控制、APRS、地图、卫星、音频及日志页面。AGWPE 是可在 Android 上运行的 TCP 网络服务。Android 还可使用 USB OTG 串口 GPS：在设置 → 地图中刷新设备、选择 USB 串口并设定波特率；首次打开时按系统提示授权。支持范围取决于 USB 串口芯片和手机 OTG 供电。USB/串口电台连接仍未接入 Android，不能由 RFCOMM 蓝牙替代。

## 开启 Android 远控服务器

1. 进入“设置 → 服务端 → 手机远程操控设置”。
2. 开启“允许局域网 / VPN 远程访问”，设置至少 12 位密码。
3. 端口可保留 8080；再开启“启用网页服务”并保存。
4. 页面会显示本机 IPv4 和 IPv6 地址；选择另一台设备可访问的地址，在浏览器打开并输入密码。IPv4 示例：`http://192.168.1.24:8080/`；IPv6 地址需加方括号，例如 `http://[240e:1234::25]:8080/`。服务优先监听双栈 IPv6 套接字，同时接受 IPv4；系统禁用 IPv6 时回退为 IPv4。
5. Android 会显示常驻通知并保持服务进程运行。停止时回到相同设置关闭网页服务。此模式需要 Android 保持网络可用，并会增加一些耗电。

局域网 HTTP 可用于登录、收听及控制，但 Android 浏览器会限制非安全页面的麦克风和定位等能力。如需在外网使用，建议接入 VPN 或将 Android 端口经 HTTPS 反向代理发布；不要直接把无 TLS 的 8080 暴露到公网。手机浏览器的麦克风和定位功能需要可信 HTTPS 页面。卫星下行跟踪可由 Android 本机使用观测位置；网页远控的数据范围仍取决于本机与浏览器权限。

## 平台边界

Android 端复用桌面相同的 Flutter 电台协议、APRS 处理、地图、频谱、卫星计算、Winlink 和远程权限逻辑，并支持本机接收语音循环录音。Android 录音片段可从音频设置逐条导出。Android 设置的“服务”选项卡还可启用 AGWPE TCP 服务器与 Home Assistant MQTT 桥接；启用任一项时，系统会显示常驻通知并保持网络服务运行。USB/串口电台适配、桌面软件更新和串口网关仍未接入 Android。USB OTG GPS 可用的芯片、设备拔插和实际定位效果仍需在目标手机与接收器上验收。

连接电台、网页服务、AGWPE、Home Assistant MQTT、持续手机定位或本机循环录音运行时，Android 显示常驻通知并持有部分唤醒锁；网页服务开启时还会保持 Wi-Fi 活跃，关闭网页服务后释放该锁。断开最后一台电台并关闭其他运行功能后会释放服务。清除应用最近任务不会主动停止已开启的服务；系统强制停止应用或厂商省电策略仍可能中断服务，需在目标手机实测。AGWPE 仅应在可信局域网/VPN中开放；它面向兼容客户端的 TCP 接口不提供远程登录密码保护。

Android 蓝牙接收队列最多缓存 128 个数据块或 512 KiB，并按块投递给 Flutter 主线程。音频积压时丢弃较旧数据以追上实时播放；控制数据保持顺序，队列达到上限时断开该 RFCOMM 连接，避免内存持续增长或把缺失字节交给协议解析器。断开原因会以固定代码写入应用日志，包括对端关闭、读取/写入失败和控制队列过载，便于判断是无线链路还是本机处理过载。队列边界单测由 Android 构建流程运行；目标手机上的长时蓝牙负载仍需实机验收。
