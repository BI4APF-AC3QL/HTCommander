# 手机远程使用 Windows 上的 N7500

Windows 负责连接 N7500 蓝牙，手机通过浏览器连接 Windows 的网页服务，不需要手机再次连接电台蓝牙。首次启用需在电脑上完成；远程访问和远程发射默认关闭。

## 电脑端

1. 使用包含 `web_app` 的 Windows 测试 Release，完整解压并运行。连接 N7500，启用电台音频以便手机收听。
2. 打开 设置 → 服务端/Servers → **手机远程操控设置 / Phone remote control settings**。
3. 开启“网页服务”和“允许局域网 / VPN 远程访问”，端口默认 8080。配置至少 12 个字符的访问密码，也可生成随机密码；密码存入 Windows 的加密凭据存储。
4. 保存后服务重新监听，旧浏览器会话失效。若 Windows 防火墙提示，允许应用在你使用的网络中通信。该功能不会自动修改防火墙、路由器或 VPN 设置。
5. 设置显示各网卡 IPv4 地址。电脑与手机同一 Wi-Fi 时，手机浏览器打开例如 `http://192.168.1.20:8080`，输入访问密码。

手机轻量控制页提供：信道 A、扫描、电台音量、手机播放音量、收听、PTT。点击“完整界面”可使用地图/APRS和已有数据视图。远程模式下完整 Flutter 界面的任意原始写入、固件升级、修改电脑设置和数据发射被限制；电台控制请使用手机专用页。信道 A 切换会选中 VFO A，PTT 使用该 VFO。

收听需点击“开启收听”，满足浏览器的音频自动播放规则。电脑要保持 HTCommander 运行、N7500 已连接且音频已启用；电脑休眠或蓝牙断开会中断远程使用。当前镜像的是电脑应用的播放音频，不是独立的第二路音频设备。

## 多个客户端的操作权

登录后可直接查看、收听。换信道、扫描、修改电台音量及提交 APRS/PTT 前，先在手机的“操作权”卡片点击“申请操作权”。同一时刻只允许一个连接操作电台；持有操作权也仍须满足独立的语音、消息、位置权限和电脑总发射许可。

- 默认情况下，空闲操作权自动授予首个有操作权限的申请者；其他申请者排队，申请两分钟后过期。
- Windows 远程设置可开启“控制权申请必须由 Windows 批准”。开启后在“在线客户端”点击相应客户端的“授予独占控制权”；该操作也会将只读客户端授权为可操作。
- 未开启主机批准时，当前操作者可以向队列中的可操作客户端移交。确认移交后停止原端讲话，并取消原端待发/重试 APRS；已交给电台的帧不能撤回。只读申请仍需 Windows 授权。
- “释放操作权”会释放自己的操作权或取消自己的申请；关闭收听不会释放操作权。Windows 可随时“收回所有远程控制权”，并清空申请队列。
- 断线、撤销登录、降为只读、切换电台、修改服务配置、紧急停止会清除相关操作权。重新连接和解除紧急停止都不会恢复旧申请或重放发送命令，需再次主动申请。

Windows 的“紧急停止远程控制与发送”与“收回操作权”不同：紧急停止期间不能重新申请，必须由 Windows 明确恢复。操作权是应用内远程操作的互斥规则，电脑本地仍可操作电台。

## 排查远程操作：脱敏审计

手机“近期操作审计”显示最近 20 条软件操作。Windows 手机远程设置中的“复制脱敏操作审计 JSON”可复制本次运行最近 200 条，粘贴到文本文件后再分享。记录含 UTC 时间、客户端连接编号、电台编号、动作和结果；客户端 0 表示主机/服务端。换信道、APRS 请求、PTT 释放、操作权授予/移交/收回、只读角色和撤销登录均可追溯。只读边界的拒绝记为通用拒绝事件。

“请求接受”只代表软件接受请求；消息 ACK、射频发送成功和蓝牙状态需要查看对应功能。审计不含密码、网络地址、呼号/消息正文、坐标或音频。记录仅在内存中保留，退出软件后清空；同一客户端的连续同类拒绝每秒至多记一次，避免异常客户端持续刷新列表。

## 外网方式一：VPN

电脑和手机加入同一个 VPN，例如 Tailscale/WireGuard。开启远程服务后，用设置中显示的 VPN IPv4 地址访问 `http://VPN地址:8080`，即可控制与收听。先启动 VPN 再启用网页服务；新增网卡后请关闭并重新开启服务以刷新允许的地址。

手机浏览器麦克风需要可信 HTTPS，即使 VPN 本身已加密，HTTP 页面也不能使用麦克风。Tailscale 用户可在启用 tailnet HTTPS 后使用 Serve：

```powershell
tailscale serve --bg http://127.0.0.1:8080
```

使用该命令返回的 `https://电脑名.你的tailnet.ts.net` 地址，在 HTCommander“外网 HTTPS 地址”中填入同一完整 origin 并保存。Serve 应保留浏览器访问的 Host，并支持 WebSocket；若代理改写 Host，请按下节配置保留。服务在 tailnet 内使用，不需要向公共互联网开放 8080。本文没有自动安装或配置 VPN。

## 外网方式二：HTTPS 反向代理

用已有域名和可信证书，将 HTTPS/WSS 转发到电脑的 `http://127.0.0.1:8080`。HTCommander“外网 HTTPS 地址”填写如 `https://radio.example.com`，自定义外部端口填写如 `https://radio.example.com:8443`；只填写 origin，不含路径、用户名、参数。

Caddy 示例（运行在同一电脑；替换域名）：

```caddyfile
radio.example.com {
    reverse_proxy 127.0.0.1:8080 {
        header_up Host radio.example.com
    }
}
```

Caddy 自动处理 WebSocket 升级。域名需正确解析到可达入口，证书与入口网络需由你的代理配置满足；没有公网入站条件时用 VPN，或你已有的 HTTPS 隧道。代理必须保留匹配配置的 Host，不要改写 Origin；HTCommander会拒绝不匹配的 Host/Origin。代理路径应位于根路径 `/`，不要只代理一个子目录。

电脑端服务本身使用 HTTP；外网 HTTPS 由代理终止。手机到入口用 HTTPS，代理到同机应用用回环连接。服务不会自动提供公网地址、配置端口映射或穿透运营商 NAT。

## 远程讲话

1. 在电脑开启总“允许发射 / Allow transmit”，开启电台音频，并在远程操控设置中单独开启“允许手机 PTT 发射”。两项发射权限都须启用。
2. 手机使用可信 HTTPS 地址登录，选择允许发射的 VFO A 信道，按住 PTT；首次允许该站点使用麦克风。松手停止。HTTP 页面保留控制/收听，PTT 显示 HTTPS 提示。
3. 单次持续 PTT 最多 60 秒；1.5 秒没有合法麦克风数据、断线、注销、切换电台、音频关闭、权限撤销、信道变化或无效/过量 PCM 会释放远程发射并取消等待音频。多个手机不能同时占有 PTT。手机切到后台或窗口失焦会发送停止并关闭麦克风。
4. 浏览器断线后会重新连接，但不会重新播放发射命令，也不会恢复按住讲话。需再次主动按住按钮。

浏览器 PTT 使用 Web Audio 的兼容捕获路径，将输入采样率转换为 32 kHz 单声道 PCM；未使用 WebRTC。延迟和音频质量受手机浏览器、网络、电脑和蓝牙连接共同影响。手机浏览器后台通常会暂停网页和音频，此版不提供后台持续工作保证。

## 登录与测试

- 登录保护同时覆盖静态文件与 WebSocket；Cookie 为 HttpOnly/SameSite Strict。HTTPS 入口使用 Secure Cookie。会话最多 12 小时，重启/修改网页服务配置会使会话失效。
- 登录表单有一次性校验值；每个来源一分钟内连续 5 次失败后暂时限流。反向代理下多个用户可能共用代理地址的限流计数。
- 不与网页同步访问密码、服务配置或总发射权限的修改。远程端不能为自己开启发射；页面中的 PTT 请求不会绕过电脑设置。
- 已验证真实 HTTP/WebSocket 登录、跨站拒绝、注销断开、默认拒绝、PTT 独占与释放定时器。手机页面脚本有独立测试，覆盖麦克风权限等待期间松手、主机授权前不发送音频、重采样和后台停止。
- 未连接 N7500 实机，未进行实际 RF 发射或外网/手机实机语音测试。先收听、换信道验证连接，再由操作者自行验收发射。支持功能不等于已验证你的蓝牙链路与 NAT/代理环境。
