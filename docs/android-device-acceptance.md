# Android 与电台实机验收

此清单用于验证 Android 版在真实手机和电台上的连接、远控与后台运行。模拟器、Flutter 单元测试和 Android 打包检查不能替代这些实机结果。

Android 发布工作流会把 x86_64 测试 APK 安装到 API 35 模拟器，启动应用并确认进程持续运行 15 秒且没有崩溃；随后用临时内存配置显示并逐个打开手机窄屏布局中的全部应用页面，包括电台、通讯、音频、APRS、地图、卫星、Winlink、终端、联系人、BBS、Torrent、数据包和诊断。该导航检查不连接电台，也不触发 PTT 或信标。工作流再通过 Android 应用启动远控服务器，从模拟器的非回环 IPv4 网卡地址直接读取登录页，并在模拟器提供非链路本地 IPv6 地址时也通过该地址读取；同时验证 ADB 端口转发路径、登录和远程操作页，以及打包的 Flutter 网页、JavaScript 与 CanvasKit 资源可由服务器读取。网页验收使用合成的接收电台状态，检查频率和操作权显示、手机端静噪与音量控件，以及两项命令均到达服务器；PTT 必须保持禁用。自动验收还会将静音 PCM 送入 Android AudioTrack，循环检查播放器建立、写入、释放和立即重启；向本机循环录音器注入两段静音合成 PCM，读取并检查 WAV 头和样本长度，并在应用退到后台时确认第二段仍能写入，关闭录音后确认前台服务释放。随后通过 ADB 端口转发从主机访问登录页；熄灭模拟器屏幕后再次访问登录页，检查网页服务在屏幕关闭时仍可连接；接着关闭网页服务，用合成电台连接单独检查 Android 前台服务能维持后台进程，并在模拟断开后释放服务；最后只开启指向本机回环地址的 Home Assistant MQTT 桥接，验证服务仍运行，并在关闭桥接后确认服务释放。合成电台和音频检查不使用真实蓝牙，也不产生 RF。模拟器结果仍不验证真实手机厂商省电策略、蓝牙射频链路、手机音频路由、长时间后台稳定性或 N7500 实机控制。

另外，Android Classic 蓝牙集成测试会在模拟的蓝牙通道上连接测试电台，启动应用自带的远控服务，再从 IPv6 回环地址完成登录并通过 WebSocket 读取电台状态。测试申请远程操作权，发送音量设置，并确认对应 GAIA 命令通过 Android Classic 蓝牙桥到达模拟传输通道；随后将应用切到后台并熄灭模拟器屏幕，确认前台服务和登录页仍可用，并在屏幕保持熄灭时通过原有认证 WebSocket 再发一条音量命令，确认 GAIA 写入仍到达模拟电台。发射选项保持关闭。它验证 Android 连接、远控和后台服务之间的集成，不代表真实手机蓝牙或 N7500 实机验收。

本地复现时，先按 [Android 构建工作流](../.github/workflows/build-android.yaml)生成包含网页资源的 Release APK，再运行 `bash src/tools/android_emulator_acceptance.sh`。脚本自动选择唯一已连接的模拟器；连接多台时通过 `ANDROID_SERIAL=emulator-5556` 指定。该测试会卸载应用以切换 Release 与集成测试签名并清除模拟器内应用数据，因此脚本会拒绝真实手机。

## 电台连接与接收

- [ ] 按 Android 版本授予“附近的设备”蓝牙权限；VR-N7500 先在系统蓝牙设置中完成配对。
- [ ] 在 HTCommander 中发现并连接电台。确认页面显示已连接，并能读到实际电台状态。
- [ ] 连接取消：开始连接后立即点断开，确认不会稍后又显示已连接；等待当前尝试结束后，再确认可以重新连接。
- [ ] 记住的电台暂时离线后重新开机或回到蓝牙范围内，确认 Android 会持续自动重连；尝试间隔最长为 5 分钟。手动断开后确认后续重连取消。
- [ ] 自动重连等待期间关闭并重新开启手机蓝牙，确认应用收到适配器恢复后会立即扫描，不会等到下一次最长 5 分钟退避；重复开关时不得出现并行连接。
- [ ] 接收电台信号，检查手机扬声器以及可用的有线、USB、蓝牙音频输出路由。
- [ ] 在安全的接收状态下测试频率、音量和静噪修改能否同步到电台，再确认电台状态能回读到应用。
- [ ] 运行扫描并手动停止，确认停止操作能及时生效。
- [ ] 记录连接耗时、断连提示、声音中断和任何界面未响应情况。

## Android 远控服务器

- [ ] 在“设置 → 服务端 → 手机远程操控设置”开启网页服务，设置密码并保存。
- [ ] 使用同一 Wi-Fi 下的第二台设备打开 Android 页面地址，确认登录页、密码校验和远程页面均正常。
- [ ] 进入电台、APRS、地图、音频和更多菜单；确认电台状态、地图数据和接收音频可显示。
- [ ] 测试只读客户端权限、未授权登录拒绝和关闭远程访问后的会话撤销。
- [ ] 按主页键并关闭屏幕 5 分钟，再从第二台设备刷新页面；确认服务仍可访问且 Android 显示常驻服务通知。
- [ ] 恢复屏幕后关闭网页服务，确认远程页面无法重新连接；再次开启服务后确认可以重新登录。
- [ ] 可选：切换 Wi-Fi 或短暂断网后恢复网络，观察服务和手机端页面能否恢复。

## 长时间接收稳定性

- [ ] 在合法、安全的接收条件下连续监听至少 30 分钟；不要执行真实 PTT、RF 发射或信标发射。
- [ ] 每 5 分钟记录一次：电台连接状态、远程页面状态、接收音频是否连续、界面是否可操作。
- [ ] 结束时检查应用日志中的蓝牙断连原因、接收队列丢弃计数和网页服务错误。
- [ ] 如果出现“未响应”、无法恢复或队列过载，记录准确时间和前后操作，并导出脱敏日志。

## 安全边界

本清单仅验证接收、连接和网页服务。不要为了验收执行真实 RF 发射、PTT 或信标测试。测试期间不要把远控端口直接暴露到公网；外网验收应使用已配置的 VPN 或 HTTPS 入口。分享日志前先移除密码、令牌、公网地址和其他个人信息。
