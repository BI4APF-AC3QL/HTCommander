# Android 与电台实机验收

此清单用于验证 Android 版在真实手机和电台上的连接、远控与后台运行。模拟器、Flutter 单元测试和 Android 打包检查不能替代这些实机结果。

Android 发布工作流会把 x86_64 测试 APK 安装到 API 35 模拟器，启动应用并确认进程持续运行 15 秒且没有崩溃；随后还会通过实际 Android 应用启动远控服务器，完成登录、访问远程操作页，并验证打包的 Flutter 网页、JavaScript 与 CanvasKit 资源可由服务器读取。该自动集成测试覆盖应用内 HTTP 监听及登录路径，但不验证蓝牙射频链路、手机音频路由、屏幕关闭后的长时间后台服务或电台控制。

## 电台连接与接收

- [ ] 按 Android 版本授予“附近的设备”蓝牙权限；VR-N7500 先在系统蓝牙设置中完成配对。
- [ ] 在 HTCommander 中发现并连接电台。确认页面显示已连接，并能读到实际电台状态。
- [ ] 连接取消：开始连接后立即点断开，确认不会稍后又显示已连接；等待当前尝试结束后，再确认可以重新连接。
- [ ] 接收电台信号，检查手机扬声器以及可用的有线、USB、蓝牙音频输出路由。
- [ ] 在安全的接收状态下测试频率、音量和静噪修改能否同步到电台，再确认电台状态能回读到应用。
- [ ] 运行扫描并手动停止，确认停止操作能及时生效。
- [ ] 记录连接耗时、断连提示、声音中断和任何界面未响应情况。

## Android 远控服务器

- [ ] 在“设置 → 服务端 → 手机远程操控设置”开启网页服务，设置密码并保存。
- [ ] 使用同一 Wi-Fi 下的第二台设备打开 Android 页面地址，确认登录页、密码校验和远程页面均正常。
- [ ] 进入电台、APRS、地图、音频和更多菜单；确认电台状态、地图数据和接收音频可显示。
- [ ] 测试只读客户端权限、未授权登录拒绝和关闭远程访问后的会话撤销。
- [ ] 按主页键并关闭屏幕 5 分钟，再从第二台设备刷新页面；确认服务仍可访问且 Android 显示常驻服务通知。
- [ ] 恢复屏幕后关闭网页服务，确认远程页面无法重新连接；再次开启服务后确认可以重新登录。
- [ ] 可选：切换 Wi-Fi 或短暂断网后恢复网络，观察服务和手机端页面能否恢复。

## 长时间接收稳定性

- [ ] 在合法、安全的接收条件下连续监听至少 30 分钟；不要执行真实 PTT、RF 发射或信标发射。
- [ ] 每 5 分钟记录一次：电台连接状态、远程页面状态、接收音频是否连续、界面是否可操作。
- [ ] 结束时检查应用日志中的蓝牙断连原因、接收队列丢弃计数和网页服务错误。
- [ ] 如果出现“未响应”、无法恢复或队列过载，记录准确时间和前后操作，并导出脱敏日志。

## 安全边界

本清单仅验证接收、连接和网页服务。不要为了验收执行真实 RF 发射、PTT 或信标测试。测试期间不要把远控端口直接暴露到公网；外网验收应使用已配置的 VPN 或 HTTPS 入口。分享日志前先移除密码、令牌、公网地址和其他个人信息。
