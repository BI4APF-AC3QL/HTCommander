# 操作权与脱敏审计验收记录

日期：2026-10-02。对应验收清单第 20、24 项。

## 已实现

- 一个浏览器连接持有独占操作权，其余连接可查看、收听或排队。队列最多 8 个请求，两分钟过期；重复申请不延长时间。
- 主机可要求审批、授予、收回、切换只读和撤销登录。只读客户端不能自动获得操作权，须由主机授权。
- 当前操作者可确认移交给待申请且可操作的连接；主机审批模式下移交由主机完成。
- 失去操作权会停止原端 PTT 并取消其待发/重试 APRS。关闭收听保留操作权；断线及紧急停止不重放旧发送请求。
- 本次运行保留最近 200 条内存审计，手机显示最近 20 条，主机可复制脱敏 JSON。审计含 UTC 时间、客户端、电台、动作和结果；不记录密码、地址、呼号、消息正文、位置或音频。
- 未知命令使用固定动作名记录；相同客户端的同类拒绝每秒至多记录一次；导出再次检查动作、结果和字段类型。
- 在线客户端与审计属于运行时状态，不写 SharedPreferences，也不会被当成持久设置恢复。

## 验证结果

- Flutter 全量 460 项通过；静态分析无问题；手机页面 Node 脚本测试通过。
- 使用生产 HTTP/WebSocket 服务和两个模拟客户端，验证独占、拒绝越权、移交后 PTT/APRS 取消、主机收回、角色变化、只读审批、紧急停止及定向注销。
- 主机设置界面在 390 × 844 视口下验证在线列表、授权、收回、紧急停止期间禁用授权；复制导出的 JSON 不含敏感字段。
- 浏览器实测申请、排队、主机授予、音量请求到达模拟后端、主机收回后禁用操作。390 像素浏览器界面验证客户端申请/音量审计的来源和显示。
- 原 Windows 卡死修复测试 Release `test-windows-36970502645-1` 下载校验通过：SHA256 `b850da3339097e1294e3d93d3dab24d645c0b472985524c2d9751223724a37ee`，ZIP CRC 和主程序、入口 EXE、网页、配置说明、验收清单、卡死报告均正常。该包不含本次新增的操作权/审计改动；须使用后续提交的测试包。

## 尚未验证

浏览器的原生移交确认框导致自动化接口阻塞，无法自动接受确认；生产服务的移交与页面确认逻辑已有模拟测试，但手机实机确认移交仍需人工验收。因此第 20 项保持 Partial。第 24 项要求的有界审计、来源、脱敏、导出和显示已有对应证据。

使用的是隔离的回环服务和模拟电台，未操作用户运行中的电台、入口，也未进行实际射频发送。此次没有捕获实际 Windows 未响应时的线程堆栈；风险修复不能证明所有卡死原因已排除。其余清单项目仍按 [完整验收清单](remote-suite-v2-plan.md) 推进。
