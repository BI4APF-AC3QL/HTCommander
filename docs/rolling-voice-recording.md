# Windows 接收语音循环录音

入口：Windows“音频”页右上菜单 → **接收语音循环录音…**。开关默认关闭。先开启电台音频，再启用循环录音；默认保留最近 **24 小时**，可选 1–168 小时。

## 保存和覆盖

- 跟随 Windows 所选的物理电台；没有显式选择时使用连接列表中第一个物理电台。32 kHz、16 位、单声道 WAV，按墙钟分钟、信道或电台变化分段；单片音频最多一分钟。
- 只保存收到的非数据音频及卫星语音下行。忽略本机/手机发射、APRS 信道、专用数据任务、被静音的信道和互联网虚拟电台。软件播放音量/扬声器静音不改变原始录音。没有语音识别：静噪打开时噪声也会保存；没有音频的空闲时间不补静音。
- 超过保留时间的完成片段自动删除。循环目录最多 6 GiB，先达到的限制生效；连续接收 24 小时原始 PCM 约 5.53 GB。开启新片段会预留一分钟空间，必要时先删最旧片段。
- **保留最新片段** 会完成正在写出的片段，移入 `kept`。已保留片段不参与自动覆盖，总量最多 1 GiB；达到上限时明确拒绝，不删除原片段。可通过目录窗口整理，再继续保留。
- **打开录音目录** 在 Windows 文件管理器查看和播放 WAV。默认目录位于应用支持目录下的 `rolling-voice`，窗口可复制完整路径。清理仅管理本功能命名的文件，不清理旧版录音目录或用户其他文件。

## 稳定性和恢复

写盘使用独立后台 isolate。主界面到写盘进程的待发数据最多 512 KiB；磁盘过慢时丢弃新音频并增加计数，不无限积压。状态每两秒刷新，可查看待发字节、丢弃字节、占用与近期片段。磁盘错误或后台异常会停止录音并显示固定错误码，接收和主界面继续工作。

关闭开关会完成当前片段。退出时尽力完成写盘，三秒无法结束时停止后台；`.part` 在下次开启时恢复可用 WAV，最后尚未写入的音频可能丢失。关闭开关不删除已有片段。录音开关和保留时长保存到本机，重新启动会按已保存的开关工作；记录文件、目录和设置不会同步到手机网页。

## 验证

真实临时文件验证 WAV 头/PCM、分段、24h 过期、容量和保留上限、部分文件恢复、用户其他文件保留及手动删除保留片段后的容量释放。十万块合成音频检验后台邮箱上限、停止完成和快速启停；存储失败可重新开启。生产 DataBroker 音频路径验证只采集所选物理电台接收语音；窄屏设置窗口验证默认 24h、启用和错误状态。

时间前进使用测试时钟，未声称已经连续运行 24 小时；没有使用用户真实音频、实际 N7500 或 RF 发射测试。
