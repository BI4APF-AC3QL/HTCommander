# 脱敏日志与离线模拟

在 Windows 的 **设置 → 服务端 → 手机远程操控设置** 中选择 **复制脱敏运行日志** 或 **离线模拟演练**。Debug 页的保存日志也导出相同的 JSON 元数据。

## 分享诊断

分享 JSON 只包含最后 200 项日志的 UTC 时间、info/error 级别与固定事件代码。消息、呼号、位置、设备地址、域名、密码、令牌、音频和异常原文全部排除，未知字段不会随嵌套数据导出。自由文本不能靠关键词保证隐私，因此分享格式不保留自由文本；需要排查连接性能时，一并复制“链路诊断”和“连接地址二维码与诊断”的脱敏计数。

本机 Debug 显示会替换当前已保存的凭据、呼号和公网地址，省略带有登录/密钥/GPS/APRS/原始帧标记的内容，并限制每条文本长度。它用于本机观察，不应当作能够分享任何任意文本的保证；截图、手动选中文本及原生插件控制台不属于上述 JSON 导出范围。

Debug 缓存最多 200 项、每条约 2 KiB，界面最多每 250 ms 收到一次不可变快照。清空与销毁会取消迟到发布，避免日志洪泛产生不断增长的列表和逐事件界面刷新。

新崩溃记录仅包含 UTC、固定错误类别及最多 12 个应用代码文件名/行列，不包含错误对象的字符串或绝对路径。磁盘写入改为串行异步队列，最多 64 项，文件达到 512 KiB 时轮换；繁忙或写入失败时丢弃日志，不阻塞界面。突然终止程序可能丢失最后的待写记录。启动会将上一次日志移到 `.1`，旧版本生成的 `.1` 可能含隐私，分享前请检查。自动填入 GitHub Issue 的正文过滤旧自由文本、读取最多最后 32 KiB，并省略用户目录路径；不会自动提交 Issue。

## 独立离线演练

1. 打开 **离线模拟演练**，顶部始终标明模拟状态。
2. 点 **模拟连接**，再点 **新建模拟 APRS**。使用固定 `DEMO-1` / `DEMO-2`，不填写或保存真实消息。
3. 对等待项点 **模拟 ACK** 或 **模拟拒收**，观察 acknowledged / rejected。
4. 新建另一项，依次点 **推进 30 秒**。虚拟时间的两次重试后，第三个间隔变为 timedOut；无需真实等待。
5. 等待时点 **模拟断开**，条目变为 cancelled。再次模拟连接不会补发。
6. 点 **模拟接收音频**，对合成的 100 ms / 1 kHz / 32 kHz 单声道数据计算标准及低带宽编码字节。它不播放声音，也不访问麦克风。

演练复用生产 APRS 投递状态机和下行编码器，但状态完全局限于对话框：没有 DataBroker、蓝牙、网络、播放器、持久化或任何真实发射调用。关闭即销毁，重开默认断开。最多保留 20 项模拟投递。本机电台和手机远控数据不会被这组虚拟状态覆盖。

## 验证范围

自动回归验证隐私边界、1000 条日志洪泛后的 200 项/4 Hz 上限、不可变快照、清空/销毁、串行磁盘队列/轮换、旧日志/Issue 过滤，以及正确/错误序号 ACK、拒收、有限重试、超时、断开取消、重连不补发和合成音频负载。390px 主机设置入口、复制和完整演练控件通过，观察到零真实 broker 请求。此演练不证明 N7500 实机或 RF 链路性能。
