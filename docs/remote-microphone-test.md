# 浏览器本机麦克风测试

登录手机远控页面，找到 **本机麦克风测试**，点击 **测试麦克风（不发射）**，允许浏览器使用麦克风，然后讲话。页面显示本机采样率、峰值、RMS 和当前音频块的削波数，每秒最多刷新十次。削波频繁出现时降低手机/声卡输入增益，或远离麦克风。

测试仅在当前浏览器测量输入，最长 10 秒，点 **停止测试** 可提前结束。没有回放、保存、音频上行或 PTT 请求；只读客户端和没有连接电台的用户也可使用。期间 PTT 禁用，已在讲话或等待 PTT 麦克风许可时不启动另一测试。

需要 HTTPS 和浏览器麦克风支持。允许等待最多 15 秒；取消、超时或切后台后的迟到许可会立即关闭麦克风。切后台、窗口失去焦点、离开页面和 WebSocket 断线均停止测试并释放输入轨道。错误只显示固定说明，不显示可能含设备/权限详情的异常原文。

自动测试执行生产页面脚本，以合成输入验证 50% 峰值/RMS、满幅削波、许可拒绝、等待超时、取消后迟到许可、十秒停止、后台/离开/失焦释放，以及零 PTT start 和零二进制上行。实际手机硬件许可、声卡增益及浏览器版本仍需在手机上执行上述步骤验收；自动测试不使用真实麦克风或电台。
