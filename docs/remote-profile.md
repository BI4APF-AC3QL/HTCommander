# 远控配置迁移

在 Windows 的“设置 → 服务端 → 手机远程操控设置”打开“远控配置导入 / 导出”。迁移范围是主程序远控、公共地图及 APRS-IS 设置，HTTPS 入口程序的域名/证书配置仍单独维护。

## 导出

点击“复制已保存配置 JSON”，将剪贴板内容保存为 UTF-8 `.json` 文件。导出的是已保存配置，当前编辑器里尚未保存的修改不包含在内。

允许导出的十项设置：网页端口、HTTPS 外网地址、默认只读角色、主机批准操作权的策略、公共地图源、APRS-IS 服务器/端口/范围、RF 路径和每分钟转发上限。

密码、认证令牌、证书/私钥、私有地图 URL/密钥、APRS 消息及模板正文、定位、音频和登录会话不导出。自定义地图源无法迁移密钥时，导出配置使用 OpenStreetMap；目标电脑可在导入后手动选择可用公共源或重新填写授权 XYZ 地址。导出不扫描磁盘、读取证书文件或枚举所有应用设置。

## 导入

1. 打开 `.json` 文件并复制内容，粘贴到导入窗口。
2. 点击“预览导入”，核对“当前 → 导入后”的字段与取值。预览不会改变配置或停止服务。
3. 勾选确认停止网页远控、APRS 网关及发射的选项，点击“应用导入”。停止动作先于端口、服务器和转发规则变更；待发的远控 APRS 请求取消，不恢复旧会话或自动重发。
4. 导入完成后重新打开设置，核对端口、外网地址、网关和地图源。原机密码及私有地图地址保留；另一台电脑须自行设置密码、授权地图源及 HTTPS 入口。需要恢复的服务/发送权限必须由操作者逐项重新开启，并显式解除远控紧急停止。

导入会立即应用并关闭原远控编辑器，父设置窗口同步刷新，避免再保存旧的端口、服务器或发射权限。预览后若另一窗口改变相关配置，会要求重新预览；重复点击不能再次应用同一计划。

文件最多 32 KiB。版本、字段、数值类型、端口、范围、RF 路径与地址均校验。未知字段、权限开关、密码字段、带用户名/查询参数的外网地址等拒绝导入；整个文件校验通过之前不写设置。错误提示不回显文件里的疑似敏感内容。
