# 手机菜单、静噪与卫星多普勒

手机登录后使用顶部五个菜单：

| 菜单 | 功能 |
|---|---|
| 电台 | 收听、信道、扫描、音量与设备静噪、操作权、PTT、卫星接收多普勒 |
| APRS | 消息草稿与确认、发送状态、会话搜索/回复、一次性位置预览 |
| 地图 | 地图换源、缩放、拖动、台站搜索与消息目标 |
| 音频 | 手机音量/起始缓冲、频谱与瀑布、本机麦克风测试 |
| 更多 | 带宽模式、运行仪表盘、网关/链路/信标诊断、审计、PWA/全屏和退出 |

诊断和高级设置默认收起。只有当前菜单的地图或频谱绘制；收听可在切换菜单时继续。切换菜单会停止当前讲话/麦克风测试，并取消未确认的 APRS/位置预览，返回后重新预览确认。

## 调静噪

先在“电台 → 操作权”申请控制，由 Windows 批准。展开“电台音量与静噪”，调节设备静噪 0–9；0 打开静噪，提高级别可能滤掉弱信号。数值来自电台设置报告，未知时禁用。只读端、无操作权、紧急停止或讲话期间不能修改。它与手机播放音量不同。

## 卫星接收多普勒

1. 在 Windows 的应用设置开启卫星支持，在卫星页更新 TLE、设置观测位置并检查卫星模式。手机使用电脑的轨道和观测位置，不覆盖位置。
2. 手机取得操作权后，展开“卫星多普勒（接收跟踪）”，选卫星和 FM 下行模式，查看方位、仰角与计算修正频率。
3. 停止扫描，确认电台没有其他任务或 PTT 占用，再点“开始接收跟踪”。轨道状态超过五秒未更新会拒绝启动；旧 TLE 即使仍能计算也可能不准确，需在电脑更新。
4. 跟踪期间禁用换信道、扫描和手机 PTT。首页频率来自电台实时频率模式报告；尚未报告时显示等待，不拿存储信道频率冒充跟踪频率。预览中的修正值是计算值。
5. 点“停止跟踪”退出；断线、释放/移交/收回操作权、改为只读、紧急停止或关闭卫星支持也会停止手机启动的跟踪。不会停止被本地用户替换的其他任务。重新连接后需重新批准和开始。

本轮手机入口提供接收跟踪，传给生产卫星引擎的上行频率为零、不设置上行亚音、不申请 PTT，不提供卫星上行讲话。电台固件对接收跟踪参数的兼容性还需 N7500 接收现场验证；软件测试仅使用模拟电台、合成轨道状态与生产计算路径。

## 测试

控制回归覆盖静噪范围/权限/紧急停止、轨道更新/观测位置/占用校验、断线与移交清理、本地任务替换保留，并通过生产 SatelliteHandler 验证零上行参数。页面脚本覆盖菜单可见性、未知值、频率报告和隐藏图形暂停；真实 Chromium 在 320/390px 检查五个菜单并通过生产 HTTP/WebSocket 调静噪、开始/停止跟踪和只读撤销。没有真实 RF/PTT/信标发射。
