# 手机低带宽接收模式

手机远控页面顶部的 **网络与接收质量 → 当前手机带宽模式** 可选择标准接收或低带宽。只读客户端也可使用，不需要操作权。各连接单独选择；切换不会修改 Windows 设置、其他手机的模式或发射许可。同一页面断线重连会重新请求当前选择，重新打开页面默认标准接收。

## 行为

| 内容 | 标准 | 低带宽 |
|---|---|---|
| 下行收听 | 主机原始采样率和声道 | 8 kHz、单声道、16-bit PCM |
| 音频频谱/瀑布绘制 | 最多 10 Hz | 最多 2 Hz，可显示到 4 kHz |
| 地图绘制 | 最多 2 Hz | 最多 0.5 Hz |
| 例行状态/地图站点刷新 | 每 2 秒 | 每 8 秒 |
| 新底图下载 | 自动、最多 8 个并发 | 点击 **加载地图瓦片** 后才下载，最多 2 个并发 |

放大、拖动、发送操作等用户请求仍立即处理。切换地图源后，低带宽模式需再次点击加载。已有瓦片缓存可继续显示；开启低带宽时已在途的瓦片请求可能完成。图形降频在手机执行，减少绘图工作；例行状态请求降频同时减少主机快照流量。控制和安全检查不延迟。

下行使用带抗混叠低通滤波的流式转换，支持 8–48 kHz 输入（包括 44.1 kHz），块边界保留采样时间。滤波历史和系数容量固定，格式变化或无人使用时清理。每输入块最多一秒；非法格式或超大块丢弃并计入无效输入块。标准模式保持 PCM 样本和格式。切换清理手机旧播放缓冲，短暂的收听中断属于预期。

低带宽适合语音，音质和音频频谱范围会降低。此选项只改变网页收听，不改变本机播放、N7500 蓝牙链路或麦克风上行；麦克风仍按现有 32 kHz 格式和发射权限处理。

## 可测量的流量

页面显示本次 WebSocket 连接的主机音频负载字节、帧数和无效输入块。字节包括每帧 4 字节头，不包括 WebSocket/TCP/TLS 开销、状态、瓦片、网页资源或上行。它表示主机提交量，不能作为网络交付确认、射频丢包率或总数据套餐用量。断线后新连接从零计数。

一秒模拟输入块的实测回环/编码负载：

| 输入 | 标准字节 | 低带宽字节 | 减少 |
|---|---:|---:|---:|
| 32 kHz 单声道 | 64,004 | 16,004 | 约 75% |
| 32 kHz 双声道 | 128,004 | 16,004 | 约 87.5% |

实际帧头开销取决于块大小。例如 20 ms 一块时，一秒分别为 64,200 / 128,200 / 16,200 字节；网络总流量还包括上述未计入内容。地图瓦片通常较大，移动网络建议保持未加载底图。

## 验证

`remote_media_test.dart` 验证负载比例、1 kHz 音量保留、6 kHz 抗混叠抑制（16/32/44.1/48 kHz）、不同块边界、单样本小块、立体声混合、子视图及非法格式。生产登录 HTTP/WebSocket 回环验证两客户端独立模式、8 kHz 帧、真实负载计数、停止收听、格式切换、新连接默认值和零 RF 命令。

手机实际脚本的模拟 8 秒计数：标准模式 80 次频谱绘制 / 16 次地图绘制 / 4 次状态请求；低带宽 16 / 4 / 1。另验证底图不自动下载、并发限制、模式重发和后台不轮询。真实 390px 浏览器通过生产 HTTP 登录/WebSocket 与模拟 1 kHz PCM 验证模式切换、持续收听、两种图形频率、增长的音频计数及停止收听；横向无溢出、控制台无错误、PTT 保持禁用。全量 512 项 Flutter 测试通过。测试使用模拟音频，未连接电台或进行真实发射。
